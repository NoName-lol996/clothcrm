# ClothCRM

面向中小型服装门店的**客户管理与跟进工具**。

门店导购最头疼的不是"记不住客户"，而是"不知道该找谁"。ClothCRM 把客户档案、消费记录和跟进计划放在一起，
每天打开首页就知道今天该联系哪几位客户。

---

## 主要功能

**数据概览**

- 客户总数、本月新增客户、本月成交客户、本月销售金额、待跟进客户数量
- 今日待跟进客户名单，点进去就能直接跟进

**客户管理**

- 客户列表、新增、编辑、删除
- 按姓名或手机号搜索
- 按跟进状态、客户来源筛选
- 每位客户包含：姓名、手机号、性别、来源、标签、最近消费、累计消费、跟进状态、下次跟进时间、备注

**客户详情**

- 基本资料一屏看全
- 跟进记录时间轴
- 消费记录列表

**跟进管理**

- 记录跟进时间、跟进内容、跟进结果、下次跟进时间
- 今天要跟进的客户按紧急程度排序
- 全部跟进记录可回看

**消费记录**

累计消费金额、最近消费时间、本月销售金额都由消费记录自动汇总，不需要手工填写。

## 本地运行

**最简单的方式**：双击项目根目录下的 `启动网站.bat`，等浏览器自动打开即可。

**手动方式**：

```bash
npm install
npm run dev
```

然后打开 http://localhost:3000

## 目录结构

```
src/
├── app/                     页面
│   ├── dashboard/           数据概览
│   ├── customers/           客户列表
│   ├── customers/[id]/      客户详情
│   └── follow-ups/          跟进管理
├── components/
│   ├── layout/              页面框架（顶部导航）
│   ├── ui/                  通用小组件（标签、头像、标题）
│   ├── customers/           客户相关组件
│   └── follow-ups/          跟进相关组件
└── lib/
    ├── types.ts             数据字段定义
    ├── constants.ts         固定选项（来源、状态、标签）
    ├── mock-data.ts         示例数据
    ├── derived.ts           统计计算（累计消费、本月销售额等）
    ├── utils.ts             日期与金额格式化
    └── data/                数据读取入口
```

> 以后接入真实数据库时，只需要改动 `src/lib/data/` 里的文件，页面代码基本不用动。
