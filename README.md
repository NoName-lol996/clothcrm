# ClothCRM

面向中小型服装门店的**客户管理与跟进工具**。

门店导购最头疼的不是"记不住客户"，而是"不知道该找谁"。ClothCRM 把客户档案、消费记录和跟进计划放在一起，
每天打开首页就知道今天该联系哪几位客户。

---

## 主要功能

**数据概览**

- 客户总数、本月新增客户、本月成交客户、本月销售金额、待跟进客户数量
- 今日待跟进客户名单，点进去就能直接跟进

**客户管理**

- 新增、编辑客户
- 删除客户（会先移入回收站，可随时恢复）
- 从 Excel / CSV 批量导入（客户资料、消费记录）
- 按姓名或手机号搜索，按跟进状态、客户来源筛选
- 每位客户包含：姓名、手机号、性别、来源、标签、最近消费、累计消费、跟进状态、下次跟进时间、备注

**客户详情**

- 基本资料一屏看全
- 跟进记录时间轴
- 消费记录列表
- 一页内完成"记录跟进""记消费""编辑资料""删除客户"

**记消费**

- 默认一笔，点「再添加一笔」可以继续加
- 一次买了三件就记三行，可以分别写清楚买了什么
- 同一个客户一次买多笔会在表格里分开呈现，累计消费和本月销售额一起算
- 底部实时显示合计金额

**跟进管理**

- 记录跟进时间、跟进内容、跟进结果、下次跟进时间
- 下次跟进时间支持"明天 / 3 天后 / 1 周后 / 2 周后 / 1 个月后"一键选择
- 今天要跟进的客户按紧急程度排序
- 全部跟进记录可回看

**回收站**

- 删除的客户先放在回收站里，不进列表、不进统计
- 随时可以「恢复」，或者「彻底删除」
- 支持一键清空回收站
- 导航上的「回收站」会显示当前有多少位客户

**导入信息**

入口在客户管理页右上角，分两类，以后还会继续增加：

*1. 客户资料*

- 支持 Excel（.xlsx）和 CSV
- 自动识别表头（姓名、手机号、来源、标签、累计消费金额……猜错了可以手动改）
- 导入前有预览，会标出哪几行资料不全、哪几位的手机号已经存在
- 手机号重复时，可以选择「跳过」或「更新已有客户的资料」
- 老客户的累计消费金额和最近消费时间可以一起带进来，会生成对应的消费记录

*2. 消费记录*

- 给已有客户补录历史订单，一笔一行
- 靠「客户手机号」找到客户（也可以改用姓名匹配）
- 需要「消费日期」和「消费金额」两列
- 系统里找不到的客户会被标出来，不会硬塞进去
- 「同一位客户、同一天、同样金额」会提示疑似重复，可以选择跳过或照样导入

两类导入都有「下载模板」按钮，照着填最省事。

**自动联动的部分**

- 记消费后：累计消费、最近消费时间、本月销售金额自动更新，客户阶段自动变成「已成交」
- 记录一次跟进后：客户的下次跟进时间自动更新，新客户自动变成「跟进中」，结果为「已成交」时阶段自动变成「已成交」
- 删除客户后：他名下的消费和跟进一并从统计里移除；恢复后原样回来

这些都不需要手工维护，避免统计对不上。

## 数据保存在哪里

目前所有数据**保存在这台电脑的浏览器里**（localStorage），刷新页面、关掉浏览器再打开都还在。

- 换一台电脑、换一个浏览器，看到的是各自的独立数据
- 清除浏览器数据会一并清掉
- 页脚有「恢复演示数据」按钮，可以一键还原成初始的示例数据

## 本地运行

**最简单的方式**：双击项目根目录下的 `启动网站.bat`，等浏览器自动打开即可。

**手动方式**：

```bash
npm install
npm run dev
```

然后打开 http://localhost:3000

## 目录结构

```
src/
├── app/                     页面
│   ├── dashboard/           数据概览
│   ├── customers/           客户列表
│   ├── customers/[id]/      客户详情
│   ├── follow-ups/          跟进管理
│   └── trash/               回收站
├── components/
│   ├── layout/              页面框架（顶部导航、页脚）
│   ├── ui/                  通用小组件（弹窗、确认框、表单字段、标签、头像）
│   ├── customers/           客户列表、详情、表单、导入向导、回收站
│   └── follow-ups/          跟进相关组件与表单
└── lib/
    ├── store.tsx            数据仓库：读取 / 保存 / 增删改 / 回收站 / 批量导入
    ├── types.ts             数据字段定义
    ├── constants.ts         固定选项（来源、状态、标签、跟进结果）
    ├── mock-data.ts         初始示例数据
    ├── import.ts            Excel / CSV 解析，客户资料与消费记录两套字段
    ├── derived.ts           统计与联动计算（累计消费、本月销售额、阶段变化）
    └── utils.ts             日期与金额格式化
```

> 数据读写全部集中在 `src/lib/store.tsx`。以后要换成真正的数据库，改动主要集中在这一个文件。
